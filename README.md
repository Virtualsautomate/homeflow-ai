# HomeFlow AI

Welcome to HomeFlow AI, an AI-powered real estate assistant developed by Virtuals Automate.

## Overview

HomeFlow AI helps real estate agents qualify leads automatically before speaking with clients.

### Features

- 24/7 AI customer support
- Buyer and renter qualification
- Lead summaries
- Contact information collection
- Move-in and budget tracking
- Property preference collection

## Future Features

- Google Sheets integration
- Email notifications
- Appointment booking
- CRM integration
- SMS notifications
